SiteBlocker – Блокировщик отвлекающих сайтов на 7 языках
Мощный инструмент для повышения продуктивности путём блокировки доступа к отвлекающим сайтам.
Работает на уровне системного файла hosts, поддерживает временную блокировку (таймер), режим Pomodoro, расписание, списки исключений и многое другое.
Реализован на семи языках программирования с единым интерфейсом командной строки.

🚀 Возможности
Добавление/удаление сайтов – команды add и remove для управления списком блокировки.

Список заблокированных – команда list показывает все заблокированные домены.

Временная блокировка – блокировка на заданное количество минут (опция -t).

Режим Pomodoro – блокировка на 25 минут с перерывом (команда pomodoro).

Авто-разблокировка – таймер автоматически снимает блокировку по истечении времени.

Расписание – блокировка по дням недели и времени (опция --schedule).

Исключения – белый список сайтов, которые не блокируются даже в режиме блокировки.

Статус – команда status показывает, активна ли блокировка и сколько осталось времени.

Цветной вывод – наглядные сообщения о действиях.

Кроссплатформенность – работает на Windows, Linux и macOS.

📖 Использование
Синтаксис (единый для всех версий):

bash
<команда> <субкоманда> [домены...] [опции]
Субкоманды
Команда	Описание
add <domain1> [domain2...]	Добавить сайты в блок-лист
remove <domain1> [domain2...]	Удалить сайты из блок-листа
list	Показать все заблокированные сайты
enable	Активировать блокировку (включает hosts)
disable	Деактивировать блокировку
status	Показать текущее состояние и таймер
pomodoro	Запустить режим Pomodoro (25 мин работа, 5 мин отдых)
clear	Очистить весь список блокировки
Опции
Опция	Описание
-t, --time <minutes>	Временная блокировка на N минут
-s, --schedule <time>	Расписание в формате HH:MM-DD:MM (например, 09:00-18:00)
-w, --whitelist	Добавить сайт в белый список (не блокируется)
-f, --force	Принудительно (без подтверждения)
Примеры
bash
# Заблокировать сайты
python blocker.py add facebook.com twitter.com youtube.com

# Временная блокировка на 30 минут
python blocker.py enable -t 30

# Запустить Pomodoro
python blocker.py pomodoro

# Показать статус
python blocker.py status

# Удалить сайт из блок-листа
python blocker.py remove facebook.com

# Заблокировать по расписанию (с 9 утра до 6 вечера)
python blocker.py enable --schedule 09:00-18:00

🧠 Как это работает
Файл hosts – программа редактирует системный файл hosts (/etc/hosts на Linux/macOS, C:\Windows\System32\drivers\etc\hosts на Windows).

Блокировка – для каждого домена добавляется запись 127.0.0.1 <domain> (или 0.0.0.0), что перенаправляет трафик на локальный компьютер.

Управление – программа хранит список заблокированных доменов в локальном конфиг-файле (~/.blocker.json), чтобы можно было легко добавлять/удалять записи.

Таймер – при временной блокировке запускается фоновый процесс, который через заданное время удаляет записи из hosts.

Расписание – фоновый процесс проверяет текущее время и автоматически включает/отключает блокировку.

✨ Дополнительные фичи
Сохранение состояния – все данные хранятся в JSON-файле, поэтому после перезагрузки системы блокировка может быть восстановлена (опция --persist).

Уведомления – в некоторых реализациях выводятся системные уведомления о начале/окончании блокировки.

Поддержка wildcard – блокировка всех поддоменов (например, *.social.com).
